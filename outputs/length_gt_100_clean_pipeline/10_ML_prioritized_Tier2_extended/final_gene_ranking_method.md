# Final ML-Prioritized Tier 2 Gene Ranking Method

Source ranking file used: `D:\genes\GeneDepresion\outputs\length_gt_100_clean_pipeline\10_ML_prioritized_Tier2_extended\ML_prioritized_Tier2_extended_all_ranked.csv`.

The final ranked list consists of Tier 2 candidate genes ordered by a composite ML-priority score. The score integrates statistical evidence from the diagnosis model with repeated ML feature-importance support across Tier2_fixed and Tier4_top-k feature-set definitions. Tier 4 is used as an additional ranked-support layer, while the reported final genes remain Tier 2 candidate genes.

Genes lower in MDD are not penalized in the Tier4 top-k feature sets because top-k selection uses the absolute value of the signed Tier4 score.

## What The Ranking Score Uses

`ML_priority_score` is a composite score clipped to the 0-1 range. It was generated by the stable ML-prioritized Tier 2 procedure using these weighted terms:

- 0.30 x `selection_frequency_combined`
- 0.20 x region-scaled `model_support_count`
- 0.15 x `sparse_model_support`
- 0.15 x `importance_rank_score`
- 0.10 x `sign_consistency_score`
- 0.05 x region-scaled statistical diagnosis evidence
- 0.05 x strict-v2 support score

The statistical diagnosis evidence score was based on `abs(standardized_effect_size_diagnosis) * -log10(p_value_diagnosis)`, scaled within region/subregion before entering the composite.

## How Tier 2 Evidence Contributes

All rows in the final ranked table are Tier 2 candidate gene-region pairs. Tier 2 provided the statistical candidate pool using nominal diagnosis evidence and standardized effect-size filtering. In this final documentation table, broad-region rows are labeled with `source_model = grouped_region_LMM`, while frontal subregion rows are labeled with `source_model = frontal_subregion_fixed_effect_sensitivity`.

## How ML Support Contributes

ML support comes from repeated feature-importance evidence across the ML v1 feature sets and the strict-v2 stability branch. The exported fields include `selection_frequency`, `model_support_count`, `sparse_model_support`, `linear_model_support`, `random_forest_support`, `mean_abs_importance`, `median_abs_importance`, `mean_rank`, and `sign_consistency`.

## How Tier4_top-k Support Contributes

Tier4_top-k feature sets are support/sensitivity layers. Tier 4 ranked signatures preserve direction with a signed score, but top-k selection uses absolute score magnitude. Therefore, both up-in-MDD and down-in-MDD genes can support the final Tier 2 prioritization. Tier 4 does not replace Tier 2 as the final reported gene pool.

## Model Support And Direction Consistency

Sparse model support captures support from L1/Elastic Net-style sparse linear models. Linear model support captures linear model coefficient evidence. Random Forest support captures exploratory tree feature-importance evidence. Sign consistency summarizes whether repeated signed linear coefficients point in the same direction. `statistical_ml_sign_agreement` records whether the ML direction agrees with the statistical model direction when both are available.

## Confidence Class Assignment

High-confidence ML-prioritized Tier 2 genes required:

- `ML_priority_score >= 0.70`
- `selection_frequency_combined >= 0.50`
- `model_support_count >= 2`
- sparse model support
- `sign_consistency >= 0.70`
- no false statistical/ML sign agreement

Moderate-confidence ML-prioritized Tier 2 genes required:

- `ML_priority_score >= 0.45`
- `selection_frequency_combined >= 0.25`
- `model_support_count >= 1`
- no false statistical/ML sign agreement

All other ranked Tier 2 rows are retained as exploratory/low-priority candidates.
